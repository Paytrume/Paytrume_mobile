Place your custom font files in this directory.

For Plus Jakarta Sans:

1. Download the font from https://fonts.google.com/specimen/Plus+Jakarta+Sans
2. Copy the `.ttf` files you need (e.g. `PlusJakartaSans-Regular.ttf`, `PlusJakartaSans-Bold.ttf`) into this folder.
3. The app loads them automatically via `App.tsx` using `expo-font`.
